# 🏢 다산 인사정보시스템 (HR Management System)

첨부된 인사 엑셀 데이터를 바탕으로 **MariaDB** 데이터베이스와 **Next.js**를 연동하여 개발된 웹 기반 인사정보 관리 시스템입니다.

---

## 🌟 주요 기능

1. **임직원 정보 조회 (Read)**
   - 첨부 엑셀 데이터 202명 사원 정보 MariaDB 적재 완료
   - 사원명, 부서명, 직급/연차 통합 검색 (실시간 디바운스 검색)
   - 부서별, 사원구분별(정직원/계약직 등), 재직상태별 필터링
   - 사원번호, 부서, 성명, 입사일, 직급/연차 기준 오름차순/내림차순 정렬
   - 페이지네이션 (10 / 20 / 50 / 100 / 전체 보기)
   - 사원 카드 클릭 시 프로필 및 입사일 기준 근속기간 자동 계산 상세 보기

2. **신규 사원 등록 (Create)**
   - `[신규 사원 등록]` 모달 폼 지원
   - 필수값 검증 및 기존 부서 자동완성(datalist)
   - 등록 즉시 MariaDB에 저장 및 목록 실시간 갱신

3. **사원 정보 수정 (Update)**
   - 각 사원 행 우측 `[수정]` 버튼으로 기존 데이터를 불러와 편집
   - 부서, 성명, 사원구분, 입사일, 직급/연차, 연락처, 이메일, 재직상태, 비고 수정 지원

4. **사원 삭제 (Delete)**
   - **단일 삭제**: 각 사원 행 우측 `[삭제]` 버튼으로 확인 팝업 후 즉시 삭제
   - **일괄 삭제**: 체크박스로 복수 사원 선택 후 `[선택 삭제 (N명)]` 일괄 삭제 지원

5. **엑셀 다운로드 (Excel Export)**
   - `[엑셀 다운로드]` 버튼 클릭 시 현재 검색/필터링 조건 또는 전체 사원 명단을 정돈된 `.xlsx` 파일로 즉시 다운로드

6. **인사 통계 대시보드 (KPI Cards)**
   - 총 임직원 수, 정직원/계약직 분포 현황, 총 부서 수 등 실시간 요약 카드 제공

---

## 🛠 기술 스택

- **Frontend & Fullstack**: Next.js (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS, Lucide React Icons, Pretendard 웹폰트
- **Database**: MariaDB 11.8 (포트 3306, `insa_db`)
- **Excel Engine**: xlsx (SheetJS)

---

## 🚀 접속 및 실행 방법

- **접속 주소**: [http://localhost:3001](http://localhost:3001)
- **개발 서버 실행**: `start.bat` 더블 클릭 또는 `npm run dev`
- **서버 종료**: `stop.bat` 더블 클릭
